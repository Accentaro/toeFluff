# Tips

## Keep overlays see-through

Some keys are meant to be translucent, like `BACKGROUND_SCRIM` (the dim behind menus) and the
`BACKGROUND_MOD_*` pills. A solid colour there covers what's underneath, so add alpha: `#00000099`. The
[key list](/) shows which defaults have alpha.

```shots
BACKGROUND_SCRIM: dim behind menus
```

## Some places only update after a reload

Discord caches a few styles. The Themes screen offers a reload button after you pick a theme.

## Profile themes are left alone

People's Nitro profile colours always show as they set them.

## Backgrounds

Backgrounds make surfaces see-through, and use `BACKGROUND_BASE_LOWER` as the tint over the image.

## Untested keys

The full catalogue includes keys that haven't shown up in the screens tested here. Switch the [key list](/) to
**All keys** to see them. A key without a screenshot isn't necessarily unused.
